# Security Policy

## Reporting Security Issues

The openGemini maintainers take security seriously. We appreciate your efforts to responsibly disclose your findings.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them through our [private vulnerability reporting](https://github.com/openGemini/openGemini/security/advisories/new) form.

For more details, see the [openGemini security policy](https://github.com/openGemini/openGemini/blob/main/SECURITY.md).
